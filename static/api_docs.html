API Testing Playground

Trang này giúp test nhanh các API GET của hệ thống mà không cần dùng Postman.

💡 Gợi ý Tính năng mở rộng cho Nhóm (Nhiệm vụ cho team)

  • Chấm công tự động: Tự động ghi nhận giờ vào ca/ra ca dựa trên thời điểm nhân viên đăng nhập/đăng xuất hệ thống.
  • Quản lý & Xếp ca làm việc: Tính năng phân ca cho nhân viên (Sáng/Chiều/Tối) để quản lý bàn giao doanh thu tiền mặt lúc đổi ca.
  • Tính năng Trả Hàng (Refund): Xử lý khách đổi/trả hàng: tạo hóa đơn trả hàng và viết Procedure cộng tự động hoàn số lượng về tồn kho.
  • In Hóa Đơn (Print Receipt): Thiết kế một popup template hóa đơn giấy nhiệt (80mm). Bấm nút in sẽ gọi lệnh window.print() của trình duyệt.
  • Tích hợp Quét Mã Vạch: Bắt sự kiện bàn phím. Khi máy quét tít mã (tương đương gõ Text + Enter) thì tự động thêm 1 đơn vị sản phẩm đó vào giỏ hàng.
  • Biểu đồ Doanh Thu: Tích hợp thư viện Chart.js vào trang Admin, gọi API /api/revenue để vẽ biểu đồ trực quan.
